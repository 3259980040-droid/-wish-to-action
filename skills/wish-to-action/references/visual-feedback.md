# 视觉反馈到修改依据

用途：将模糊审美反馈转为能观察、比较和修改的依据；不把更多形容词当作视觉规格。

先确认当前作品、对应版本和参考能否实际查看。把用户评价与其当时看的版本绑定。截图只能支持静态观察；节奏、动作、音画关系需要动态材料，不从局部抽帧推断整片通过。

从实际作品与参考的差异中选择有解释力的维度：构图与焦点、信息层级、字形与阅读、色彩与明暗、材质与细节、动作与停顿、镜头及转场。不要每次都全量分析。

区分三件事：
- 观察：画面中实际可见的特征。
- 解释假设：该特征可能如何影响阅读、情绪或风格。
- 偏好决定：用户想保留什么、舍弃什么；参考只在已选维度上有约束力。

形成轻量修改依据：当前证据 → 希望发生的可观察变化 → 一次适度修改 → 比较方式。例如多处同等明亮可能让主读区不明确，可尝试降低一个辅助区的对比，再比较目标尺寸下第一眼落点是否清楚；这不是适用于所有画面的固定规则。

用少量有区别的选项、局部样稿或短片段帮助用户反馈，保留“都不喜欢”以及重新找方向的可能。给生成工具输入参考素材与人工分析参考是两种不同操作，遵循当前任务对素材使用的约束，不擅自互相替代。

没有作品或参考时，可先建立候选维度和取得材料的办法；不要声称已经诊断了未看到的作品。审美结论注明依据与观察范围，技术检查通过不等于审美通过。
